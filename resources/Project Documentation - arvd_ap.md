# **Project Overview: arvd\_ap**

**arvd\_ap** is a lightweight Python utility module created as a hands-on learning project to explore Python package and module development, structuring, and distribution. It brings together a collection of fundamental programming utilities covering basic mathematics, number theory, strings, and text analysis into a reusable package.

## **Key Features & Functions**

| Function | Category | Purpose   |
| :---- | :---- | :---- |
| avg() | Mathematics | Calculates the average of a set of values. |
| sign() | Mathematics | Determines the sign of a number. |
| perfect\_num() | Number Theory | Checks whether a number is a perfect number. |
| armstrong\_num() | Number Theory | Checks whether a number is an Armstrong number. |
| palindrom\_num() | Number Theory | Checks whether a number is a palindrome. |
| primality() | Number Theory | Determines whether a number is prime. |
| fib() | Number Theory | Generates or calculates Fibonacci values. |
| vowel\_count() | String Analysis | Counts vowels in a string. |
| consonant\_count() | String Analysis | Counts consonants in a string. |
| space\_count() | String Analysis | Counts spaces in a string. |
| palindrome\_str() | String Analysis | Checks whether a string is a palindrome. |
| word\_count() | String Analysis | Counts words in a string. |
| alpha\_count() | String Analysis | Counts alphabetic characters. |
| int\_count() | String Analysis | Counts integer/numeric characters. |
| div\_it() | Mathematics | Performs division-related functionality. |

## **Installation**

The package can be installed via PyPI using pip:  
`pip install arvd_ap`

## **Project Purpose** 

This project was developed as a hands-on learning exercise to understand how Python modules are structured, packaged, and distributed. It aggregates several fundamental programming exercises into a single package.
